# Orchard

A phone-first guide to the produce worth buying at the supermarket right now. Each item gets a verdict (Peak, Good, Skip or Limited evidence) with its reasons, plus how to pick, store and ripen it. It's built for a phone propped on a shopping cart, with an offline in-store mode.

**Status:** pre-build. See [PROGRESS.md](PROGRESS.md).
